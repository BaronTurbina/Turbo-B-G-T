TURBO BUDŻET — PAKIET GITHUB 2026

Wersja zawiera:
- grafikę tła z DeLoreanem DMC-12 od tyłu i tablicą OUT A TIME,
- menu pod przyciskiem trzech poziomych kresek,
- ekran „Od autora” z emblematem Baron Turbina z numerem 24,
- dotychczasowe funkcje budżetu, PIN, kategorie, wybór 20 języków i instrukcję.

INSTALACJA: rozpakuj ZIP i wgraj CAŁĄ zawartość do głównego katalogu repozytorium GitHub Pages, zastępując stare pliki. Zachowaj foldery assets/ oraz icons/. Następnie poczekaj na publikację GitHub Pages i odśwież stronę.

Uwaga: nie wgrywaj samego index.html — potrzebne są także grafiki, manifest, service worker i foldery.


Wersja aplikacji: v1.0. Wypłatę miesięczną można edytować przyciskiem „Edytuj wypłatę miesięczną / budżet” na panelu głównym lub przez ikonę ustawień. Zmiana zapisuje nową kwotę dla wybranego miesiąca i przelicza budżet.


Aktualizacja v1.2: przy dodawaniu wpłaty można wybrać oszczędności albo budżet bieżącego miesiąca. Wpłatę do budżetu można rozłożyć równo na tygodnie lub przypisać do wybranego tygodnia. Wpłata przypisana do tygodnia zwiększa jego limit; wpłata równa zwiększa limity wszystkich tygodni o równą część.


Wersja 1.3 – poprawki rozliczeń wpłat: dodatkowe wpłaty budżetowe są uwzględniane w tygodniowych i miesięcznych limitach, nie są podwójnie liczone dla starszych wpisów bez alokacji, zmniejszają zapotrzebowanie na oszczędności po przekroczeniu budżetu, a zamknięcie miesiąca uwzględnia wszystkie wpłaty budżetowe. Zmieniono identyfikator cache Service Workera.
